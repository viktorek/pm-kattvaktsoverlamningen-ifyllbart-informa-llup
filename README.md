# Kattvaktsöverlämningen – ifyllbart informationskit

Den här webbplatsen är skapad och publicerad automatiskt av Pengamaskinen.

- `index.html`: webbplatsens startsida
- `images/`: bilder till sidan
- `nedladdning/`: produktfilen som kunden får efter betalning
- `sitemap.xml`, `robots.txt`: för sökmotorer
- `indexnow-3362d395.txt`: ägarbevis för sökmotoranmälan (IndexNow)
- `.nojekyll`: gör att GitHub Pages publicerar filerna som de är

Webbplats: https://viktorek.github.io/pm-kattvaktsoverlamningen-ifyllbart-informa-llup/
